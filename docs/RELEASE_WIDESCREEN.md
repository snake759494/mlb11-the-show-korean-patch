## 16:9 와이드 패치 (PCSX2 전용) — `SCUS-97657_7892EFCF.pnach`

이 릴리즈에 함께 첨부된 `.pnach` 파일을 넣으면 경기 화면이 16:9 와이드로 나옵니다. 원본 ISO와 한글패치 ISO 모두 쓸 수 있습니다.

### 적용 방법 (PCSX2 1.7 / 2.x)
1. 릴리즈에서 `SCUS-97657_7892EFCF.pnach` 를 받습니다. **파일 이름을 바꾸지 마세요**(게임 CRC `7892EFCF` 로 찾습니다).
2. PCSX2 메뉴 **도구 → 데이터 디렉터리 열기**로 연 폴더 안의 `patches` 폴더에 파일을 넣습니다.
   (폴더가 없으면 `patches` 폴더를 새로 만듭니다. 휴대용 설치는 PCSX2 실행 파일 옆의 `patches` 폴더입니다.)
3. 게임 목록에서 MLB 11 을 **우클릭 → 속성 → 패치** 탭을 엽니다.
4. **Widescreen 16:9** 항목에 체크합니다.
5. 게임을 실행하면 화면 비율이 자동으로 16:9 로 바뀝니다.
   화면 왼쪽 위에 "1개의 게임 패치가 활성화되었습니다"가 뜨면 적용된 것입니다.

### 참고
- 원리: 게임에 원래 들어 있는 와이드 카메라(Hor+, 가로 시야 4/3배)를 항상 켭니다. 화면을 단순히 늘리는 방식이 아닙니다.
- 메모리의 원래 코드와 일치할 때만 적용되는 조건부 패치라, 다른 화면에서는 아무것도 바꾸지 않습니다.
- 메뉴·HUD 같은 2D 화면은 가로로 늘어나 보입니다(게임 자체 와이드 모드와 동일).
- 끄려면 4번의 체크를 해제하고, 설정 → 그래픽의 화면 비율을 원래 값(자동 4:3)으로 돌립니다.
